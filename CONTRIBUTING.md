# Contributing

Thanks for your interest in improving AltairMini BBS Monitor – Mystic Edition.

## Before submitting changes

- Explain the problem and the expected behavior.
- Keep changes focused; preserve existing date ranges, statistics, cache behavior, and the compact mobile-friendly layout unless the change explicitly targets them.
- Do not include real Mystic logs, private user information, IP addresses, credentials, or local machine paths beyond generic examples.
- Test Python syntax before opening a pull request:
  ```bash
  python -m py_compile dashboard.py run_monitor.py
  ```
- Include screenshots only after removing private information.

## Pull requests

Describe what changed, why it changed, how it was tested, and any known limitations.
