# Security Policy

## Scope

This project is a local/LAN monitoring dashboard for Mystic BBS. The current version does not provide authentication or HTTPS.

## Safe deployment

- Keep the service on localhost or a trusted private LAN.
- Restrict TCP port 8765 using Windows Firewall.
- Do not expose the service directly to the public Internet.
- Do not submit real BBS logs or screenshots containing private user data in public issues.

## Reporting a vulnerability

Please do not publish credentials, private logs, IP addresses, or exploitable details in a public issue. Contact the repository maintainers privately through the contact method listed on the GitHub profile/repository, if available.
